# 챗봇 고정 메시지

- 최초 안내: 거래 시각·금액·입출금 방향과 처리 보류 사실
- 최초 질문: `본인이 한 거래가 맞나요?`
- 유형 확정 팝업: `{유형}이/가 의심돼요, 대응 가이드를 알려드릴게요.`
- 가이드 후: `대응 가이드 이외에 추가로 질문하고 싶은 것이 있다면 말씀해주세요.`
- 상담사 연결: 판별 불가 안내, 전화 예정 안내, 대기 중 자유 질문 안내
- 정상 가이드: 사기 가능성이 낮다는 안내와 고객센터 `1599-9999`, 영업점 해제 안내

팝업은 채팅 메시지가 아니라 `fraud_type_confirmed` SSE 이벤트다. RAG 스냅샷보다 먼저
전송하며 재접속 조회에서는 반복하지 않는다.
