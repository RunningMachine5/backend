# FDShield 보이스피싱 의심거래 고객 안내

> FDShield 팀 프로젝트 시연용 안내이며 실제 발송 전 금융회사의 승인 문구로 교체해야 한다.

## 거래 확인 안내

탐지된 거래의 일시와 금액을 고객이 확인할 수 있도록 안내하고 본인이 요청한 거래인지 묻는다.
사기 피해가 확정되었다고 표현하지 않고 이상 징후가 확인되어 확인이 필요하다고 설명한다.

## 즉시 중단할 행동

기관이나 금융회사를 사칭한 상대방과의 통화 및 추가 송금을 중단하도록 안내한다. 상대방이
요구하는 앱 설치, 인증번호 전달, 현금 인출을 진행하지 않도록 한다.

## 피해가 의심되는 경우

이미 송금한 경우 이용 금융회사와 수사기관의 공식 채널로 신속하게 신고하도록 안내한다.
구체적인 지급정지와 피해구제 절차는 최신 공식 안내 문서를 함께 제공한다.

## 안내 시 주의사항

고객에게 비밀번호, OTP, 보안카드 번호 전체를 요구하지 않는다. 이메일의 1·2순위 유형은
의심 유형으로 표현하며 고객의 범죄 피해나 가담을 확정적으로 단정하지 않는다.
