# FDShield 사기이용계좌 의심거래 고객 안내

> FDShield 팀 프로젝트 시연용 안내이며 실제 발송 전 금융회사의 승인 문구로 교체해야 한다.

## 거래 관계 확인

입금자, 실제 거래 상대방, 물품이나 서비스의 전달 대상이 서로 일치하는지 확인하도록 안내한다.
개인 간 거래에서 제3자 명의로 입금된 경우 거래를 계속하기 전에 사실관계를 확인한다.

## 추가 자금 이동 주의

입금된 금액을 다른 계좌로 보내거나 현금·가상자산·상품권 등으로 바꾸라는 요청을 받았다면
추가 처리를 중단하고 금융회사의 공식 채널에 문의하도록 안내한다.

## 확인자료 보존

거래 게시글, 대화 내용, 입금자 정보, 물품 전달 내역을 보존하도록 안내한다. 계좌 명의인의
고의 가담 여부는 자동으로 단정하지 않으며 담당자가 거래 문맥을 확인한다.

## 계좌 관련 안내

계좌 제한이나 지급정지 가능성을 확정적으로 안내하지 않는다. 관련 조치가 필요한 경우 금융회사의
담당자가 최신 법령과 내부 절차를 확인하여 별도로 설명한다.
