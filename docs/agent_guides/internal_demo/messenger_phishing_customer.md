# FDShield 메신저피싱 의심거래 고객 안내

> FDShield 팀 프로젝트 시연용 안내이며 실제 발송 전 금융회사의 승인 문구로 교체해야 한다.

## 상대방 신원 확인

송금을 요청한 가족이나 지인에게 기존에 알고 있던 전화번호로 직접 연락하도록 안내한다.
메신저에 새로 전달된 전화번호나 링크를 신원 확인 수단으로 사용하지 않는다.

## 송금 및 정보 제공 중단

신원이 확인될 때까지 추가 송금, 상품권 구매, 신분증 사진과 인증정보 전달을 중단하도록 한다.
메신저 계정의 이름과 사진만으로 실제 가족이나 지인이라고 판단하지 않는다.

## 피해 확인자료 보존

대화 내용과 상대방 계정, 송금 요청 시각, 송금 내역, 수취계좌를 삭제하지 않고 보존하도록
안내한다. 가능하면 대화 화면과 상대방 프로필을 캡처하고, 이체확인증과 받은 링크·전화번호를
함께 정리한다. 이미 송금한 경우 보존한 자료를 준비해 금융회사와 수사기관의 공식 채널로
피해 사실을 신고하도록 한다.

## 안내 표현

현재 거래는 메신저피싱 의심 정황이 있어 확인 중이라고 표현한다. 고객의 확인 전에는 피해가
확정되었다거나 특정 상대방이 범죄자라고 단정하지 않는다.
