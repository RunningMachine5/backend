# FDShield 계정탈취 의심거래 고객 안내

> FDShield 팀 프로젝트 시연용 안내이며 실제 발송 전 금융회사의 승인 문구로 교체해야 한다.

## 본인 거래 확인

고객에게 탐지 거래의 일시와 금액을 확인하도록 안내한다. 본인이 수행하지 않은 거래라면 추가
금융거래를 중단하고 금융회사의 공식 고객센터를 통해 즉시 확인하도록 한다.

## 단말 보안 점검

최근 설치한 출처 불명의 앱과 원격제어 앱 사용 여부를 확인하도록 안내한다. 의심 연락에서 받은
링크나 앱을 다시 실행하지 않고 안전한 다른 기기에서 공식 연락처를 확인하도록 한다.

## 인증정보 보호

비밀번호, OTP, 인증번호를 타인에게 전달하지 않도록 안내한다. 인증수단 변경이 필요하면 문자나
메신저의 링크가 아니라 금융회사의 공식 앱 또는 공식 고객센터를 이용하도록 한다.

## 피해 신고

본인이 수행하지 않은 거래가 확인되면 이용 금융회사와 수사기관에 신고하고 거래내역과 연락 기록을
보존하도록 한다. 구체적인 조치는 최신 금융회사 절차에 따른다.
