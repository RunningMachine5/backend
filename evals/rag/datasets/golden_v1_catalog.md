# RAG 골든셋 v1 ID 카탈로그

이 문서는 `golden_v1.jsonl`의 100개 평가 사례를 ID별로 검토하기 위한 자동 생성 문서다. 데이터의 원본은 JSONL이며, 이 문서는 생성 스크립트를 실행할 때 함께 갱신된다.

## 필드 해설

- `유형`: 검색·응답 동작을 구분하는 `category`
- `기대 동작`: 답변, 추가 질문, 답변 거절 중 기대하는 동작
- `PDF 근거`: 모범 답변을 뒷받침하는 문서와 실제 PDF 페이지
- `필수 주장`: 답변 채점 시 반드시 포함되어야 하는 핵심 내용
- `태그·구조`: 평가 슬라이스와 조건 분기·추론·질의 분해 구조

41~45번은 `single_hop` 채점 기준을 그대로 사용한다. 다만 고객 행동은 앞 페이지에, 대응 가이드는 다음 페이지에 있는 사례이며 `page_boundary`, `behavior_page:*`, `guide_page:*` 태그로 별도 집계할 수 있다.
