# 골든셋 카탈로그 (golden_v1)

`golden_v1.jsonl` 100건을 id 순으로 정리한 표다. 생성이 아니라 사람이 작성했고,
근거는 `pypdf` 로 뽑은 PDF 페이지 원문을 그대로 잘라 넣었다.
`tests/test_rag_golden_dataset.py` 가 모든 근거의 PDF 실재 여부를 대조한다.

작성 규칙은 [README](../README.md) 를 따른다.

1. 질문은 **고객이 자기 상황을 서술하는 말투**로 쓴다 (행동·정보 노출·접촉 한 줄 포함).
2. 모범답변은 **질문에 답하는 만큼만** 쓴다. 근거 페이지를 요약하지 않는다.
3. 무근거 사례는 **코퍼스가 다루지 않는 주제**로 고른다. 절차가 코퍼스에 있으면
   실행을 요구하는 질문이라도 답변 가능이다.
